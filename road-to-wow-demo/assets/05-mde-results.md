## 3b. ความไม่สมมาตรของชุดคำถามนี้ — เสีย 1 ก้อน เจ็บกว่าได้ 1 ก้อน ราวสองเท่า

นับเป็นรายคู่ (query, resolution): ก้อนที่ **ยังไม่เจอ** (มีให้ได้เพิ่ม) กับก้อนที่ **เจอแล้ว** (มีให้เสีย)
มูลค่าของแต่ละก้อนคือ 1/gold_n ของคำถามนั้น

- ก้อนที่ยังไม่เจอ: 289 ก้อน มูลค่าเฉลี่ยก้อนละ **0.0774**
- ก้อนที่เจอแล้ว: 355 ก้อน มูลค่าเฉลี่ยก้อนละ **0.1426**
- อัตราส่วน = **1.84 เท่า**

เหตุผล: ก้อนที่ยังไม่เจอกระจุกอยู่ในคำถามที่มี gold เยอะ (แต่ละก้อนจึงมีค่าน้อย)
ส่วนก้อนที่เจอแล้วกระจุกอยู่ในคำถามที่มี gold น้อย (แต่ละก้อนจึงมีค่ามาก)

**ผลตรง**: ถ้าระบบใหม่พลิกก้อนแบบสุ่มด้วย churn 0.75 (ได้ 4 เสีย 3) ผลสุทธิจะเป็น
-0.1181 ต่อรอบ — **ติดลบ** ระบบที่ churn สูงแบบสุ่มจึงไม่ได้แค่พิสูจน์ยาก แต่ **แย่ลงจริง**
ระบบที่ดีขึ้นจริงจึงต้องเลือกก้อนที่ได้ ไม่ใช่พลิกแบบสุ่ม

## 4. ต้องมีกี่คำถามถึงจะพิสูจน์ผลขนาดที่ 'เกิดขึ้นจริงแล้ว' ได้

ไม่จำลองผลกระทบสมมติอีกต่อไป — ใช้ **เวกเตอร์ diff ต่อคำถามที่วัดได้จริง** จากคู่ระบบที่มีอยู่
แล้วสุ่มซ้ำ (resample with replacement) ให้ได้ n คำถาม เพื่อตอบว่า 'ถ้ามีคำถามแบบนี้ n ข้อ
จะพิสูจน์ความต่างขนาดที่เห็นอยู่แล้วได้มั้ย' — ไม่มีสมมติฐานเรื่อง churn หรือขนาดผลเลย

ตัวเลขคือ power (สัดส่วนที่ได้ p<0.05) **ก่อน** Holm — ถ้าทดสอบหลายสมมติฐานต้องหารความไวลงอีก

## 5. ผลข้างเคียงของ bootstrap แบบนี้เมื่อระบบใหม่ 'ดีขึ้นอย่างเดียว'

ถ้าไม่มีคำถามไหนแย่ลงเลย diffs จะไม่ติดลบสักตัว ทำให้ p ของ bootstrap แบบ percentile เท่ากับ
2 x (สัดส่วนที่สุ่มได้แต่คำถามที่ diff=0) = 2 x (n_zero/n)^n ซึ่งเล็กมากแม้พลิกแค่ 1-2 คำถาม
- ถ้าพลิก 1 คำถาม: p ทฤษฎี = 2 x (72/73)^73 = 7.31e-01
- ถ้าพลิก 2 คำถาม: p ทฤษฎี = 2 x (71/73)^73 = 2.63e-01
- ถ้าพลิก 3 คำถาม: p ทฤษฎี = 2 x (70/73)^73 = 9.35e-02
- ถ้าพลิก 5 คำถาม: p ทฤษฎี = 2 x (68/73)^73 = 1.13e-02
- ถ้าพลิก 10 คำถาม: p ทฤษฎี = 2 x (63/73)^73 = 4.27e-05

**นี่คือจุดที่ตัวเลข power ข้างบนต้องอ่านอย่างระวัง**: power สูงในตาราง churn=0 ไม่ได้แปลว่าเครื่องมือวัดไว
แต่แปลว่าสมมติฐาน 'ดีขึ้นอย่างเดียว' นั้นแรงเกินจริง ตาราง churn>0 คือกรณีที่ควรใช้ตัดสิน
